tabmv 规则

平时用侧边栏就够了，这里给需要批量编辑的人。每行一条：网址匹配 => 标签名 [; icon=…] [; color=…]，从上到下第一条命中生效，# 开头为注释。⌘/Ctrl+S 保存。

语法

* ? [a-z] [!&]glob，整串匹配（anchored）；* 最短匹配；\ 转义
{a,b} (a|b)选择；( ) 是捕获组，和 zmv 一样引用：{1} 或 $1
无 ( ) 时每个 * / ? / […] 自动成为捕获组（zmv -W）
(#i)前缀，忽略大小写（zsh glob flag）
/regex/iJS 正则，部分匹配；支持 (?<name>…) → {<name>}
title:前缀，匹配原标题而不是 URL
标签名：普通文字照原样显示，{…} 是一段可变内容，{{ }} 表示花括号本身
{page ".title"}页面上第一个匹配这个 CSS 选择器的元素的文字（侧边栏点选会自动生成）
{?env}网址参数（也查 #/route?env=）
{host} {host[1]} {host[-2]}域名 / 第 1 段 / 倒数第 2 段
{path} {path[2]}路径 / 第 2 段
{title} {url}原标题、完整网址
{1} {<name>}网址匹配里的第 1 个捕获组 / 正则命名组
A or B or "文字"取不到就用后面的。页面元素还没渲染时先用后面的，渲染出来后自动换回
before "." after "-"只要分隔符前面 / 后面的部分
match /#(\d+)/按正则取出括号里的部分；没匹配到算取不到
replace /re/ "x" upper lower trim max 20替换、大小写、去空白、截断
旧写法$1 $title ${q.env|before:.} ${sel:h1 || 1} 仍然可用
icon=emoji、letter（新标题首字）、1–2 个字符、图片 URL、none
color=CSS 颜色或 auto（按第 1 个捕获组算出固定颜色）；只给 color 时在原图标右下角加色点
