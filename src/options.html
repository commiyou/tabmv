tabmv 规则

每行一条：pattern => title [; icon=…] [; color=…]，从上到下第一条命中生效，# 开头为注释。⌘/Ctrl+S 保存。

语法

* ? [a-z] [!&]glob，整串匹配（anchored）；* 最短匹配；\ 转义
{a,b} (a|b)选择；( ) 是捕获组，和 zmv 一样用 $1 引用
无 ( ) 时每个 * / ? / […] 自动成为捕获组（zmv -W）
(#i)前缀，忽略大小写（zsh glob flag）
/regex/iJS 正则，部分匹配；支持 (?<name>…) → $<name>
title:前缀，匹配原标题而不是 URL
$1 ${12} $&捕获组 / 整个匹配
$title $url $host $path原标题、URL、host、path
${q.env}查询参数（也查 #/route?env=）
${sel:h1.title}页面上第一个匹配 CSS 选择器的元素的文字；选择器里有空格等特殊字符时写 ${sel:"…"}。侧边栏里点选会自动生成
${a || b || "文字"}兜底：从左到右第一个非空的值。页面还没渲染出元素时先用后面的，渲染出来后自动换回
${x|filter}upper lower trim max:20 default:- before:. after:- s/re/rep/g m/re/（取第一个捕获组，没匹配到为空，可触发兜底）
icon=emoji、letter（新标题首字）、1–2 个字符、图片 URL、none
color=CSS 颜色或 auto（按 $1 哈希出固定颜色）；只给 color 时在原图标右下角加色点
